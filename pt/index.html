MindHug

 Principal

Solução multiplataforma abrangente em KMP

MindHug é uma aplicação de apoio à saúde mental construída do zero em Kotlin Multiplatform puro. Incorpora os princípios do desenvolvimento multiplataforma moderno: lógica de negócios unificada, UI nativa via Compose Multiplatform e localidade total de dados sem servidores ou análises.

Stack Tecnológico

 KMP  Compose Multiplatform  Kotlin
Android
iOS

Arquitectura Limpa

Clean Architecture + MVI. Separação de camadas, testabilidade, escalabilidade.

Privacy by Design

Zero análises. Todos os dados são armazenados localmente. Sem servidores, sem rastreadores.
